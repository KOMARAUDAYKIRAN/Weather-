# 🌦️ Weather Forecast Web Application

A dynamic **Weather Forecast Web App** that provides real-time weather data and a 5-day forecast using the OpenWeatherMap API.  
This project demonstrates API integration, asynchronous JavaScript, responsive UI design, and real-time data handling.

---

## 🚀 Features

### 🌍 Current Weather Data
- City-based weather search
- Temperature in Celsius
- Humidity, wind speed, and weather conditions
- Country and city details

### 📅 5-Day Weather Forecast
- Displays daily temperature
- Weather icons for each day
- Organized forecast cards

### 🎨 Dynamic UI
- Background changes based on weather condition
- Clean and responsive design
- Weather icons from API

### ⌨️ Smart User Interaction
- Search using **Enter key**
- Input validation
- Error handling for invalid cities

### ⏳ Loading Indicator
- Spinner shown while API data is being fetched
- Better user experience

### ⚡ Performance & Code Quality
- Async/Await API calls
- Modular JavaScript functions
- Efficient DOM updates

## 🐳 How to Run the Project

1. Download or clone the repository
2. Open the folder
3. Replace the API key in `script.js`:

```javascript
const apiKey = "YOUR_API_KEY";
```

4. Open `index.html` in browser
